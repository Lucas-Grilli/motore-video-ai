# Contribuire

Questo repo è principalmente un puntatore (HyperFrames + ElevenLabs) più tre esempi: la parte più utile non è "aggiungere codice qui dentro", è segnalare dove il prompt o gli esempi non bastano.

## Segnalare un problema

Apri una issue. È utile soprattutto: un pattern HyperFrames che gli esempi non coprono, un passo del prompt di auto-setup che si è rotto o è ambiguo, una voce o un parametro ElevenLabs che vale la pena documentare.

## Proporre una modifica

Pull request benvenute su: nuovi esempi (con licenza chiara sugli asset), correzioni al README, fix negli esempi esistenti. Mantieni lo stile "Design decisions" del README — una scelta, il perché, in poche righe — invece di spiegazioni lunghe.

## Cosa non aspettarsi

Nessun supporto per motori diversi da HyperFrames o voci diverse da ElevenLabs: sono le due scelte su cui questo repo è costruito, non un adattatore universale.
