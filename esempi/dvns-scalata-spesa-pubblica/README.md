# DVNS — La scalata della spesa pubblica

Reel di 24 secondi, non parlato: un solo numero (la spesa pubblica italiana) che sale sullo schermo nell'ultimo decennio, mentre la sua quota sul PIL resta quasi ferma (50,7% → 50,4%) — +34% in termini nominali.

**Cosa mostra tecnicamente:**
- Composizione minimale: nessuna voce, nessun elemento di distrazione — solo tipografia, numero e una progress-bar sul PIL.
- Tutto il messaggio essenziale vive nel riquadro 4:5 centrale del formato 9:16, leggibile anche nell'anteprima ritagliata di Instagram/TikTok.
- È l'esempio giusto per capire il timing puro (`data-start`, `class="clip"`) senza la complessità aggiuntiva di una voce da sincronizzare.

**Render:**

```bash
npm run render
npm run check
```

Dato, fonte e metodo: [Dove Vanno I Nostri Soldi](https://www.dovevannoinostrisoldi.com/) — sistema editoriale sui conti pubblici italiani, dato sempre verificato e datato, nessuno scostamento presentato come accusa.
